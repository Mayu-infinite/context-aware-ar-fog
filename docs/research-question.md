# Research Question

## Primary question

Can real-time visual-spatial context understanding be used to select an
appropriate external walking cue for environmental situations associated
with Freezing of Gait?

## Technical hypothesis

A context-aware cueing system that combines scene perception, spatial
reasoning and temporal context can provide more contextually appropriate
feedback than a fixed cueing strategy.

## Initial scope

The first stage does not attempt to diagnose Parkinson's disease or directly
detect Freezing of Gait.

Instead, it investigates:

1. Scene perception
2. Spatial context recognition
3. Action selection
4. Cue selection
5. Real-time performance

## Later scope

Gait/FoG sensing may be added after the environment-aware system has been
validated technically.
